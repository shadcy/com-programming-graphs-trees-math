# Tree Traversals & Basic Properties

## Key Concepts
- **Depth**: Distance from the root node.
- **Height**: Longest simple path from a node to any leaf in its subtree.
- **Subtree Size**: Number of nodes in the subtree rooted at node $u$ ($1 + \sum \text{size}(v)$).
- **Diameter**: The longest path between any two nodes in a tree. Can be found using **2-DFS / 2-BFS** in $O(N)$ time.
