# Graph Traversals & Connected Components

## Key Concepts
- **BFS (Breadth-First Search)**: Finds shortest paths in unweighted graphs in $O(V + E)$.
- **DFS (Depth-First Search)**: Explores branches fully, used for component finding, cycle detection, and connectivity.
- **Bipartite Graph (2-Coloring)**: A graph is bipartite if vertices can be divided into 2 sets such that no two vertices in the same set are adjacent. Equivalent to: **contains NO odd-length cycles**.
